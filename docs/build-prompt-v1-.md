Build a web application called BookRank.

Purpose:
Allow users to build the definitive ranking of their reading history through head-to-head book comparisons.

Tech Stack:

* Next.js
* Supabase
* Supabase Auth
* Open Library API
* Elo ranking system

Pages:

* Landing page
* Login page
* Library page
* Compare page
* Rankings page
* Profile page

Core Functionality:

* User authentication
* Search and add books
* Store books in personal library
* Present head-to-head comparisons
* Update Elo scores after each comparison
* Display rankings

Design:

* Clean
* Minimal
* Mobile-friendly
* Similar aesthetic to Goodreads/Letterboxd/Beli
