# BookRank
A platform that helps readers create the definitive ranking of their reading life through head-to-head comparisons.

## Problem

Goodreads tracks books but does not help users rank them against one another, making rankings feel artbitrary.

## MVP

- Add books
- Compare books
- Generate rankings

## Current Status

App skeleton (placeholder pages). Docs remain the source of product truth.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
